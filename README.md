# Cosmic Atlas

An interactive 3D atlas of the observable universe, from the Earth–Moon system (about 10^7 m) out to the cosmic microwave background, with flat ΛCDM cosmology telemetry.

## How to run

It's a single self-contained file. Download `index.html` and open it in any modern browser. No install or build step needed.

## Live demo

Enable GitHub Pages (Settings → Pages → Branch: `main`, folder `/root`) and the atlas will be live at:

`https://mujtabaahmadi548-007.github.io/<repo-name>/`
